## 👨‍💻 About

Statistician turned AI engineer, based in Seoul. At **Danusys** I single-handedly built the CCTV analytics model stack and the MLOps pipeline around it. Before that: LLM/RAG products (**Petobio**), time-series anomaly detection (**LeverLock**), sports statistics (**Genius Sports**).
